1 ·Le participe passé

Trois cas suffisent pour la quasi-totalité des écrits professionnels. COD = complément d'objet direct : on le trouve en posant la question « quoi ? » après le verbe. Pour ENTENDRE l'accord, remplacez le participe par mis ou pris : le féminin « envoyée » ne s'entend pas, « mise » et « prise » s'entendent. Le test révèle le féminin ; le pluriel se déduit du mot repris.

CasLa règleExemples justes
Avec êtreLe participe s'accorde avec le sujet. « Ont été » compte comme être (forme passive).La demande est acceptée · Les factures ont été envoyées
Avec avoirPas d'accord avec le sujet. Le participe s'accorde avec le COD, à condition qu'il soit placé AVANT le verbe (que, la, les…).Nous avons reçu vos pièces · Les pièces que vous avez fournies · Ces documents, nous les avons signés
Verbe pronominal courantS'engager, s'apercevoir, se tromper… : accord avec le sujet. Attention : pas d'accord quand le verbe est suivi d'un complément direct (se permettre de, se rendre compte) ou quand « se » veut dire « à soi » (se téléphoner, se parler).Votre conseillère s'est engagée · Nous nous sommes aperçus de l'erreur · Nous nous sommes permis de vous relancer
Le testRemplacez par mis / mise ou pris / prise. La même astuce donne la lettre finale : subie → subi, sans t ; prise → pris, avec s.Les pièces que vous avez prises → que vous avez fournies
LE PIÈGE DU « QUE »« Les pièces que vous avez fournies » : le « que » reprend « les pièces », placé avant le verbe. L'accord se fait donc, alors même que l'auxiliaire est avoir.

2 ·Le bon mode après certaines expressions en « que »

Certaines expressions imposent le subjonctif, d'autres l'interdisent. Repérez d'abord laquelle précède le verbe ; puis, pour ENTENDRE la bonne forme, remplacez le verbe par faire : « que vous fassiez » est un subjonctif, « que vous faites » un indicatif.

Après…Le modeExemples justes
il faut que, afin que, pour que, bien que, avant queSubjonctifIl faut que vous envoyiez · afin que nous puissions · bien que le délai soit dépassé
après que, parce que, pendant que, dès queIndicatifAprès que vous avez signé · après que nous aurons reçu le bon
si de condition + présentFutur, présent ou impératif dans l'autre partieSi vous nous transmettez le RIB, nous effectuerons le virement
si de condition + imparfaitConditionnel dans l'autre partieSi vous pouviez nous rappeler, nous en serions ravis
LA RÈGLE DU SI DE CONDITIONQuand si veut dire « à condition que », jamais de conditionnel juste après : on écrit « si vous pouviez nous rappeler », pas « si vous pourriez ». Ne pas confondre avec le si d'une question indirecte, où le conditionnel est correct : « nous aimerions savoir si vous pourriez nous recevoir ».

3 ·Les conjugaisons qui piègent

Quelques formes reviennent sans cesse dans les mails et se voient immédiatement quand elles sont fausses.

FormeLa bonne écritureÀ ne pas écrire
faire, dire avec vousvous faites · vous dites (seuls dire et redire font « dites » : vous contredisez, vous prédisez)vous faîtes · vous faisez · vous disez
prierje vous prie d'agréer…je vous pris · je vous prit
résoudre au futurnous résoudronsnous résolverons
appeler, rappeleril rappellera · nous appellerons : deux l devant un e muet (mais nous appelons)il rappelera
Le sujet éloignéLe verbe s'accorde avec son sujet, même loin : « Les frais de dossier vous incombent »Les frais de dossier vous incombe
LE RÉFLEXEAvant d'envoyer, cherchez le sujet de chaque verbe : beaucoup de fautes d'accord viennent d'un mot placé entre les deux.

4 ·À retenir

  1. Avec être, on accorde avec le sujet. Avec avoir, on n'accorde qu'avec un COD placé avant.
  2. Mis, pris : remplacez le participe pour entendre l'accord ; remplacez le verbe par « faire » pour entendre le subjonctif.
  3. Jamais de conditionnel juste après le « si » de condition. Après « après que », l'indicatif.
  4. Vous faites, vous dites, je vous prie, nous résoudrons : quatre formes à connaître par cœur.
